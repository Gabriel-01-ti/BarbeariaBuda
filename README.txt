BLACK & GOLD BARBERS — SITE COMPLETO

Arquivos:
- index.html: site público e agendamento
- admin.html: painel do barbeiro
- styles.css: visual responsivo
- app.js: serviços, equipe, disponibilidade e armazenamento dos agendamentos
- admin.js: login, dashboard, filtros, status, cadastro manual e configurações

COMO USAR
1. Abra index.html no navegador.
2. Faça um agendamento como cliente.
3. Acesse "Área do barbeiro" no rodapé ou abra admin.html.
4. Login de demonstração:
   E-mail: admin@barbearia.com
   Senha: 123456

IMPORTANTE
Esta versão é uma demonstração front-end. Os dados ficam no localStorage do navegador. Para colocar online com dados compartilhados entre vários celulares/computadores, substitua o armazenamento por um backend/banco de dados (por exemplo Firebase, Supabase ou API própria) e implemente autenticação real.
